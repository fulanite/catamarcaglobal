# Design System

## Paleta

- Violeta profundo: `#4712A8`
- Violeta global: `#6522C7`
- Magenta: `#E81264`
- Coral: `#FF3344`
- Naranja: `#FF7200`
- Blanco: `#FFFFFF`
- Blanco suave: `#FAF9FC`
- Lila claro: `#F2ECFA`
- Borde gris: `#DDD9E5`
- Texto: `#181126`
- Texto secundario: `#4D4758`

El degradado institucional se usa en botones, badges y acentos. No debe dominar fondos extensos salvo CTA o bandas de impacto.

## Tipografías

- Montserrat: títulos, navegación, botones y etiquetas.
- Inter: párrafos, formularios y contenido editorial.

## Espaciados

- Contenedor máximo: `1280px`.
- Padding móvil: `20px`.
- Padding escritorio: `32px`.
- Secciones: `64px` móvil, `96px` escritorio.

## Componentes

- Header sticky con navegación desktop y menú móvil.
- Botones primarios con degradado y secundarios con borde violeta.
- Tarjetas institucionales con borde suave, sombra ligera y hover moderado.
- Formularios con etiquetas reales, errores accesibles y foco visible.
- Organigrama responsive sin scroll horizontal.

## Variantes

- `section--soft`: fondo blanco suave.
- `card--accent`: tarjeta institucional destacada.
- `btn-secondary--light`: botón secundario para fondos oscuros.
- `editable-note`: aviso para contenido no confirmado.

## Responsive

- Mobile first desde 320px.
- Tablet desde 640px.
- Desktop desde 1024px.
- Wide desde 1440px.

Reglas clave: grillas apiladas en móvil, botones táctiles de al menos 44px, menú móvil con bloqueo de scroll, tipografía por media queries y organigrama vertical en pantallas chicas.
